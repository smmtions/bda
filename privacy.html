Privacy Policy

Billion Dollar Autopsy publishing tool · Effective October 25, 2026

The "BDA YouTube Agent" is a private tool used only by the owner of the YouTube channel Billion Dollar Autopsy to publish that channel's own videos. It is not offered to the public and has no other users.

What the tool accesses

With the channel owner's permission, the tool uses the YouTube Data API and YouTube Analytics API to:

  • upload and schedule the channel's own videos, and set their titles, descriptions, tags and thumbnails;
  • read the channel's own statistics (subscribers, views, watch time) to plan future videos.

What it does not do

  • It does not access any other person's YouTube account or data.
  • It does not collect, sell or share personal data of viewers or anyone else.
  • It does not use YouTube data for advertising.

Storage and security

The authorization token is stored privately by the channel owner and is used only to make the API calls listed above. Channel statistics are kept in the owner's private project files for planning.

Google and YouTube

The tool uses YouTube API Services. By using it you are also bound by the YouTube Terms of Service and the Google Privacy Policy. Access can be revoked at any time at Google security settings.

Contact

Questions can be sent through the channel's YouTube page: youtube.com/@BillionDollarAutopsyTV.
